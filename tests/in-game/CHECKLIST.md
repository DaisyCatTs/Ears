# In-game test pack

Generated by `cd common && ./gradlew testSkins`. Every skin here is written by the same
code path the manipulator uses, so if one of these renders wrongly in Minecraft, the
editor's preview is wrong about it too.

## How to run it

1. Build and install: `./build.sh` then `install-test.fish`, or drop a jar from
   `release/` into a 1.21.11 or 26.1 profile.
2. Upload a skin below to the account you are testing with, or use a skin-changer mod.
3. Look at yourself in third person (F5), then check the row.

Compare each against https://skin.daisy.cat with the same file loaded — the preview and
the game should agree. Where they disagree, the game is right.

## If something is wrong

Note which skin and what you saw. The fixture name maps straight onto
`tests/fixtures/`, and `common/src/main/java/com/unascribed/ears/common/EarsRenderer.java`
is where the geometry for every feature lives.
